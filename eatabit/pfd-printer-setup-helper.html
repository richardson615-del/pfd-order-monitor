PFD Printer setup helper

1. Join this computer to the printer's own WiFi (it is named PFD-Printer- and four letters or numbers).
2. Then use one of the forms below. Both talk straight to the printer at 192.168.4.1.

Set the store WiFi

Use this when the printer's page is stuck on "Looking for WiFi networks". Type the name exactly as it appears on the router, capitals included. 2.4 GHz networks only.

Install new firmware

Pick pfd-eatabit-2.8.5-update.bin. It takes about a minute, then the printer restarts by itself. Don't unplug it while it runs.
