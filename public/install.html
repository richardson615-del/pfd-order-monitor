Install PFD Orders

Open this page on the tablet, not on a computer.

Download the app

About 1 MB. Android will ask whether to allow installing from Chrome — that prompt is normal, say yes.

After it downloads

  1. Open the downloaded file and tap Install.
  2. Open PFD Orders from the home screen.
  3. Sign in with the username and password from the CRM.
  4. Tap Enable notifications and allow it. Nothing will chime until this is done, and it can only be done here on the device.

Then, from the office

  1. Send a Test order from the CRM and check it reports reaching at least one device. Zero means notifications were not enabled.
  2. Press Accept on the tablet to stop the chiming. Only Accept stops it.
  3. Only once that works, turn the tablet on for the restaurant.

If the download is blocked, open Chrome's menu → Downloads and tap the file there. The app updates itself whenever the dashboard changes — you only reinstall if this page says to.
